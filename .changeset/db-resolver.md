Add `@bedrock-core/db` with the host resolver: probe a target for where its documents can live —
its own dynamic properties through the engine's six-method or component ABI, or a world property
keyed by its identity when it holds nothing — with one adapter over both ABIs, a capability record
per host, refusals by name for an `ItemStack` and a stackable slot, and a per-type cache that never
caches a throw.
